# 听见校园：隐私优先的声景地图

**作品编号**：400552
**参赛赛项**：数字艺术与可视化设计类
**作品形式**：单文件网页作品（`index.html`），浏览器直接打开即可运行，无需安装、无需联网、无外部素材依赖。

## 这是什么

只记录「哪里安静、哪里嘈杂」，不录音、不定位到人：把声环境做成可看的地图。

## 怎么看

- **在线看**：`https://junming49.github.io/campus-soundscape/` —— 打开就是这件作品本身，页面上没有任何通往其它作品的入口。
- **本地看**：下载本仓库，双击 `index.html`。

## 可核验的内容

- **源码与提交历史**：本作品源码副本存于公开仓库 `github.com/junming49/blue-boundary-coral-reef` 的 `sound.html` 一页，`commits/main` 可逐次核对每一处改动的时间与内容。
- **边界声明**：页面内的「作品说明」抽屉逐项写有设计取舍、数据来源、虚构与示意的部分，以及**尚未开展**的工作——未做的事不写成已完成。
- **零外部依赖**：图形全部由代码 / SVG 绘制，未引用第三方图片、字体、图标、音频素材。
